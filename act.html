Activities

Practice what you learned

Activity 1: Quick quiz

1. Which is an example of hardware?

2. A website whose content changes by user, time, or database is:

3. Who protects networks and data from cyberattacks?

4. A fake bank email asking you to log in is:

5. Netiquette is a combination of:

Activity 2: True or False

Choose True if the statement is correct. Choose False if it is wrong.

1. Software is a physical device that you can touch.

2. The internet connects devices so they can share data.

3. A static website shows the same content to all visitors.

4. Phishing uses fake emails or websites to trick people into giving personal information.

5. If someone bullies you online, you should reply angrily right away.

6. Using the same password for all your accounts is a safe habit.

Activity 3: Identification

Type the correct answer on the line. Spelling counts, but capital letters do not.

1. What do you call the technologies used to create, store, and communicate information?

2. What is the collection of web pages that we open through the internet using a browser?

3. What do you call the rules of online courtesy?

4. Which ICT professional protects computers, networks, and data from cyberattacks?

5. What do you call unwanted bulk messages, often with harmful links or ads?

6. What is the term for malicious software such as viruses, spyware, and ransomware?
